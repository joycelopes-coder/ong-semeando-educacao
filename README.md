# Semeando Educação — Esboço

Template mínimo com React + TypeScript + Vite + Tailwind + Framer Motion + Lenis.

Instalação:

1. npm install
2. npm run dev

Observações:
- O projeto já inclui arquivos de configuração para Tailwind (tailwind.config.cjs, postcss.config.cjs).
- Ajuste versões em package.json conforme necessário.
- Lenis import é simples; se houver aviso de tipagem, instalar @types ou ajustar import/assinatura.
